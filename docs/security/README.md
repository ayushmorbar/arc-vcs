# arc Security Documentation

This directory contains operational security guidance for maintainers and contributors.

## Documents

- `threat_model.md`: STRIDE-oriented threat model and trust boundaries.
- `incident_response_playbook.md`: incident handling lifecycle from triage to postmortem.
- `coordinated_disclosure.md`: coordinated disclosure and advisory publication policy.

## Usage

- Update these documents whenever architecture changes affect attack surface.
- Keep this content aligned with root `SECURITY.md` and release processes.
