# Coordinated Disclosure Policy

## Reporting Channels

- Preferred: GitHub Private Vulnerability Reporting on this repository.
- Alternative: maintainer security contact listed in root `SECURITY.md`.

## Maintainer Commitments

1. Acknowledge receipt within 72 hours.
2. Provide triage status and next-step timeline.
3. Keep reporter informed through key milestones.
4. Credit reporters unless anonymity is requested.

## Disclosure Modes

### Standard: Patch With Advisory

Use when a fix can be developed and validated privately before publication.

### Early Advisory

Use when there is active exploitation, unavoidable public disclosure, or high user benefit from immediate awareness.

## Publication Targets

- GitHub Security Advisory (primary)
- RustSec advisory entry when applicable
- changelog/security note for released fixes

## Embargo Expectations

- Report details remain private during remediation unless agreed otherwise.
- Maintainers may shorten embargo when user risk is high.
- Reporters should avoid public PoC publication before coordinated release.
