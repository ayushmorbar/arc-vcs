# arc Examples

This directory contains idiomatic arc walkthroughs focused on reproducible CLI workflows and deterministic testing.

- `01-quickstart-cli.md`: create a repository, capture snapshots, inspect history.
- `02-multicall-dispatch.md`: invoke `arc` via executable stems such as `arc-sync` and `arc-daemon`.
- `03-deterministic-fixtures.md`: deterministic fixture orchestration for robust test suites.
- `04-env-isolation.md`: isolate environment variables safely in tests.
